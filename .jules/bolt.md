## 2026-09-18 - Background Polling Optimization
**Learning:** Multiple components (`FastMCPStatusBadge`, `WatchtowerBeacon`, `KeepHall`, `FastMCPGatewayStreamer`) implement independent polling loops using `setInterval`. This is a common performance bottleneck in dashboards as these continue polling aggressively even when the browser tab is not visible, leading to unnecessary API calls, battery drain, and general performance degradation over time on client devices.
**Action:** Always verify if a polling `setInterval` requires execution while the document is hidden. A simple `if (document.hidden) return;` at the beginning of the interval callback is a lightweight optimization that drastically improves background tab performance.

## 2026-09-21 - Phaser Distance Calculation & Speed Normalization
**Learning:** In `ui-v2` Phaser game loops (`update`), avoid using `Math.hypot` for distance comparisons and vector normalization in high-frequency frame ticks as it creates a measurable performance bottleneck. Instead, use pure vector normalization (`dx / Math.sqrt(...)`) and squared distance checks (`dx*dx + dy*dy < radius*radius`).
**Action:** Apply pure vector normalization in `ui-v2/src/lib/hall/locomotion.ts` and scene update loops to ensure 60fps performance without subpixel camera/movement jitter.
