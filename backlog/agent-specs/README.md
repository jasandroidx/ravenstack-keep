# Agent Spec backlog (drafts only)

Draft Agent Specs land here as `<id>.agent-spec.draft.json` via Keep MCP `propose_agent_spec`.

- **Never** draft-to-execute: drafts are not live agents.
- Promote with `approve_spec(confirm=true)` → `agents/<id>.agent-spec.json`.
- Room unlock is a separate human gate.

This directory is created intentionally so operators and agents do not treat a missing path as a silent failure.
